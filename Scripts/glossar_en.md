# FicsitTD Glossary German -> English (binding for all translations)

Vanilla Satisfactory items, buildings and creatures: always the official English game names.
Lookup: `C:\Program Files (x86)\Steam\steamapps\common\Satisfactory\CommunityResources\Docs\de.json` (German) and `en-US.json` (English), same ClassName in both.
Examples: Eisenbarren = Iron Ingot, Eisenplatte = Iron Plate, Eisenstange = Iron Rod, Schrauben = Screws, Draht = Wire, Kabel = Cable, Beton = Concrete,
Kupferblech = Copper Sheet, Stahlträger = Steel Beam, Stahlrohr = Steel Pipe, Verstärkte Eisenplatte = Reinforced Iron Plate, Rotor = Rotor,
Modularer Rahmen = Modular Frame, Schwarzpulver = Black Powder, Rauchschwaches Pulver = Smokeless Powder, Quarzkristall = Quartz Crystal,
Rohöl = Crude Oil, Treibstoff = Fuel, Turbotreibstoff = Turbofuel, Schweröl­rückstand = Heavy Oil Residue, Verdichtete Kohle = Compacted Coal,
Fabrikator (Assembler) = Assembler, Konstruktor = Constructor, Raffinerie = Refinery, Gießerei = Foundry, Schmelzofen = Smelter,
Baupistole = Build Gun, Förderband = Conveyor Belt, Rohr = Pipe, MAM = MAM, AWESOME-Sink = AWESOME Sink, AWESOME-Shop = AWESOME Shop,
Hog = Fluffy-tailed Hog, Alpha-Hog = Alpha Hog, Klippen-Hog = Cliff Hog, Nuklear-Hog = Nuclear Hog, Spucker = Plasma Spitter, Stinger = Stinger, Krabbe = Flying Crab.
