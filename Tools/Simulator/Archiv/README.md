# Archiv

Einzelwerkzeuge bis 24.11.2026: Eichungen, Sweeps, Varianten und Diagnosen für bestimmte Fragen. Nicht mehr gepflegt und
nicht mehr gegen den aktuellen Code geprüft. Sie importieren `strategien`/`simulator` aus dem Ordner darüber und laufen nur,
wenn man sie dorthin zurückkopiert.

Warum archiviert: Fünf Werkzeuge eichten dieselbe Verlustkurve mit eigenen Filtern (`verlust_fit_013`, `kalibriere`,
`p12_fit`, `residuen_tuerme`, dazu `verlust_fit` im Ordner darüber). Seit 24.11. gibt es eine Messquelle (`messungen.py`) und
eine Pflichtprüfung (`abgleich.py`), siehe README darüber.
