# Feedback form / Rückmeldebogen (Vorlage für Google Forms o. ä.)

> **Stand 0.10.2** (15.11.2026). Bei jeder Version mit neuen Türmen, Modi oder Systemen hier nachziehen (Namen wie im Handbuch).

Marius legt daraus ein Formular an. Fragen zweisprachig, Antworttyp in Klammern.

1. Mod version / Mod-Version (Text, steht in SMM und im Kern-Menü)
2. PC: CPU, GPU, FPS in waves / FPS in Wellen (Text)
3. Language played / Gespielte Sprache (Deutsch, English)
4. Game mode / Spielmodus (Auswahl: Operation / Einsatz – 50 waves; started by hand in the Core Menu / von Hand im Kern-Menü gestartet – Short/Kurz 20, Medium/Mittel 30, Standard 50, Endless/Endlos)
5. Highest wave reached / Höchste erreichte Welle (Zahl)
6. Play time / Spielzeit in Stunden (Zahl)
7. Turrets used / Benutzte Türme (Mehrfachauswahl: Bolt Turret, Rifle Turret, Nobelisk Launcher, Tesla Coil, Flamethrower, Sky Tower, Singularity Launcher)
8. Buildings used / Benutzte Bauten (Mehrfachauswahl: walls/gate, lure fire, oil slick, electric fence, drone pad, others)
9. Fun / Spaß (1–5)
10. Difficulty waves 1–10 / 11–20 / 21–30 / 31–50 (je: too easy/zu leicht, fine/passt, too hard/zu schwer, not reached/nicht erreicht)
11. Was it clear what to do? / War klar, was zu tun ist? (1–5, plus Freitext)
12. Combos noticed / Kombos bemerkt (Mehrfachauswahl: Lightning Rod/Blitzableiter, Heat Crack/Hitzeriss, Deflagration/Verpuffung, Oil Fire/Ölbrand, Chokepoint/Engstelle, Rally Point/Sammelpunkt, Conductor/Leiter, none/keine)
13. Coupons and Hard Drives: enough, too few, too many? / Coupons und Festplatten: genug, zu wenig, zu viel? (je Auswahl)
14. Pioneer: main role and did your own fighting matter? / Pionier: Hauptrolle und hat dein eigenes Kämpfen etwas ausgemacht? (Auswahl Marksman/Schütze, Commander/Kommandant, Engineer/Techniker, Hunter/Jäger; 1–5)
15. Bugs (what, which wave) / Fehler (was, welche Welle) (Freitext, Datei-Upload für Log/Screenshot; Hinweis auf „Report bug / idea“ im Kern-Menü)
16. Best moment / Bester Moment (Freitext)
17. Most annoying / Was nervte am meisten (Freitext)
