# FICSIT Tower Defense (FicsitTD)

A Satisfactory mod that turns the game into a factory-fed tower defense: defend a FICSIT Defense Core against waves of native fauna, with turrets that consume real ammunition produced by your factory.

**Status:** Alpha (0.9.0), single-player, Windows (Steam and Epic). German and English.

Install via the [Satisfactory Mod Manager](https://ficsit.app). Start a new game and enable the session setting **"FICSIT Tower Defense"**.

## Building

Requires the [SML Starter Project](https://docs.ficsit.app/satisfactory-modding/latest/Development/BeginnersGuide/index.html) (SML 3.12, Unreal Engine 5.6 CSS). Clone this repository into `Mods/FicsitTD` of the starter project, build the editor, then package with Alpakit.

- `Source/` – C++ (gameplay, waves, turrets, Core menu)
- `Content/` – assets, mostly generated by the Python scripts in `Scripts/`
- `Scripts/` – asset generation, translation table (`uebersetzung_en.json`)
- `Tests/` – automated self-test packages

Code comments and internal notes are mostly German.
